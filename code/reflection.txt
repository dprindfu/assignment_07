In this assignment, I learned how to account for different formattings of webpages in the web scraping process and also a bit more about HTML in general and how pages are layed out with different tags. I also learned about applying "fuzzy matching" when two names represent the same thing but might be spelled out slightly differently. This matching isn't always perfect and is why we need input from humans about which wordings are equivalent to make the system as accurate as possible. This also gave me process on crafting data pipelines to funnel data from websites into a dashboard useful for a stakeholder.
